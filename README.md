# Задача: Доработка CRM для управления переводчиками

## Описание задачи
Необходимо доработать функционал CRM системы для управления переводчиками с учетом их графика работы.

## Требования

### Типы переводчиков
1. **Штатные переводчики** - работают только в будние дни (Пн–Пт)
2. **Внештатные переводчики** - доступны только в выходные дни (Сб–Вс)

### Требования к системе
1. **База данных**:
    - Добавить таблицу `translators` с полями:
        - `id` (уникальный идентификатор)
        - `name` (ФИО переводчика)
        - `type` (тип: `full_time` / `part_time`)
        - `available_days` (дни доступности: `weekdays` / `weekends`)

2. **Функционал**:
    - Реализовать CRUD-интерфейс для управления переводчиками
    - Обеспечить выборку переводчиков в зависимости от дня недели (будни/выходные)

### Технические требования
1. Развернуть проект на **Yii2 Advanced** в **Docker**
2. Использовать **миграции** для создания БД
3. Реализовать **API/View** для отображения списка переводчиков (можно на Vue.js)
4. Весь код должен быть закоммичен в **Git** (локально и удаленно)


## Порядок установки проекта

* Клонирование проекта `` git clone https://github.com/seddikur/translators.git``
* Запуск Docker `` docker-compose up -d ``
* Переход в контейнер  `` docker-compose exec -it php bash ``
* Запуск установки расширений yii2 `` composer install ``
* Инициализация yii2 `` php init ``

настройка соединения bd
common/config  main-local.php
````
 'db' => [
            'class' => \yii\db\Connection::class,
              'dsn' => 'mysql:host=translators-db-1;dbname=yii',
            'username' => 'root',
            'password' => 'secret',
            'charset' => 'utf8',
        ],
````

* Запуск миграций `` php yii migrate ``
* Запуск скрипта для создания пользователей `` php yii user/create-users``

Скрипт создаст:
Пользователя с ролью админ (логин / пароль): admin / 12345
Пользователей с ролью менеджер (логин / пароль): manager1 / 12345 , manager2 / 12345
Пользователей с ролью юзер (логин / пароль): user1 / 12345 , user2 / 12345
