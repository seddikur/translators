# Описание проекта

## Backend

### TasksController.php

Контроллер реализует CRUD-действия для модели Tasks. Реализованы следующие методы:

- **actionIndex**: Отображает список всех задач.
- **actionView**: Отображает детальную информацию о задаче по указанному ID.
- **actionAppoint**: Назначает переводчика на задачу по указанным ID задачи и ID переводчика.
- **actionCreate**: Создает новую задачу. При успешном создании перенаправляет на страницу просмотра.
- **actionUpdate**: Обновляет существующую задачу. При успешном обновлении перенаправляет на страницу просмотра.
- **actionDelete**: Удаляет задачу по указанному ID. При успешном удалении перенаправляет на список задач.
- **findModel**: Вспомогательный метод для поиска задачи по ID. Если задача не найдена, выбрасывает исключение 404.

### TranslatorController.php

Контроллер управляет переводчиками. Реализованы следующие методы:

- **actionIndex**: Отображает список всех переводчиков.
- **actionView**: Отображает детальную информацию о переводчике по указанному ID.
- **actionCreate**: Создает нового переводчика. При успешном создании перенаправляет на страницу просмотра.
- **actionUpdate**: Обновляет информацию о переводчике. При успешном обновлении перенаправляет на страницу просмотра.
- **actionDelete**: Удаляет переводчика по указанному ID. При успешном удалении перенаправляет на список переводчиков.
- **findModel**: Вспомогательный метод для поиска переводчика по ID. Если переводчик не найден, выбрасывает исключение 404.

### API

#### TranslatorController.php (API)

REST контроллер для работы с переводчиками через API. Реализованы следующие эндпоинты:

- **GET /translator**: Получение списка всех переводчиков
- **GET /translator/{id}**: Получение информации о конкретном переводчике
- **POST /translator**: Создание нового переводчика
- **PUT /translator/{id}**: Обновление информации о переводчике
- **DELETE /translator/{id}**: Удаление переводчика

## Frontend

### Vue.js компоненты

#### TranslatorsList

Компонент для отображения списка переводчиков (`frontend/web/js/translators.js`). Функциональность:

- Отображение таблицы переводчиков с полями: ID, ФИО, Тип, Дни доступности
- Кнопки действий: Просмотр и Удаление
- Автоматическая загрузка списка при монтировании компонента
- Форматирование отображения типа занятости и дней доступности
- Подтверждение удаления переводчика

#### TranslatorView

Компонент для просмотра детальной информации о переводчике (`frontend/web/js/translators.js`). Функциональность:

- Отображение полной информации о переводчике
- Форматирование отображения типа занятости и дней доступности
- Кнопка возврата к списку переводчиков
- Автоматическая загрузка данных при монтировании компонента

### Конфигурация

#### URL правила

В `backend/config/main.php` настроены URL правила для API:

```php
'urlManager' => [
    'enablePrettyUrl' => true,
    'showScriptName' => false,
    'rules' => [
        [
            'class' => 'yii\rest\UrlRule',
            'controller' => [
                'api/tasks',
                'api/translator',
            ],
            'pluralize' => false,
        ],
    ],
],
```

### Зависимости

Frontend использует следующие библиотеки:
- Vue.js - для построения пользовательского интерфейса
- Vue Router - для маршрутизации
- Axios - для HTTP-запросов
- Bootstrap - для стилизации компонентов
